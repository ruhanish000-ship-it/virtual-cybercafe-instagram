# Virtual Cyber Cafe — Free Permanent Instagram Automation

This project creates and publishes a professional 9:16 Instagram Reel plus a matching 4:5 feed post for **[@virtual_cybercafe](https://www.instagram.com/virtual_cybercafe/)**. It rotates through the configured cyber-cafe services, checks selected official government/exam pages for new notices, writes separate Instagram-ready captions, generates an original instrumental background track, and publishes through Meta's official API.

The permanent core does **not** require a paid AI subscription. Gemini is optional; if its free quota or model is unavailable, the built-in professional caption system takes over automatically.

## What is automated

- Daily Reel and matching feed post at **7:30 PM IST** through GitHub Actions.
- 1080 × 1920, browser-friendly H.264 Main/AVC video with AAC-LC 48 kHz audio.
- A clear **3.65-second opening hook**, slow cinematic zoom and smooth scene transitions.
- Five branded Reel scenes, cover, separate captions, relevant hashtags and DM call-to-action.
- Matching professional 1080 × 1350 feed graphic with a different, shorter caption.
- Instagram uses one caption field; the searchable description, CTA and hashtags are combined there automatically.
- Original locally generated background music — no downloaded song and no music subscription.
- Rotation across Aadhaar, PAN, Voter ID, passport, certificates, driving/vehicle work, admissions, job forms, business registration, travel and document services.
- Checks only allowlisted official SSC, UPSC, DSSSB, NTA and RRB pages for new notices.
- First run creates a baseline so old notices are not announced as new.
- Exact official notice title is used; the bot never invents a fee, date, eligibility condition or vacancy count.
- Duplicate-post prevention and automatic encrypted Instagram-token refresh.
- Dry-run safety mode before automatic publishing is enabled.

## Important requirement

Instagram automatic publishing works only with a **Professional (Business or Creator)** account. For this business, choose **Business**. The Instagram Login method used here does not require a Facebook Page, but it does require a Meta developer app and these permissions:

- `instagram_business_basic`
- `instagram_business_content_publish`

Meta's publishing API must be able to download the Reel from a public URL. The workflow therefore keeps only the current generated Reel on a dedicated public `instagram-media` branch. Your access token is never placed there.

## Zero-cost architecture

| Part | Free option used |
|---|---|
| Scheduler/server | GitHub Actions in a public repository |
| Graphics | Pillow |
| Reel encoding | FFmpeg |
| Background music | Original music generated by this project |
| Publishing | Official Meta Instagram API |
| Caption writing | Built-in templates; optional Gemini free tier |
| Temporary media hosting | Dedicated GitHub branch containing only the current Reel |

No third-party service can promise “lifetime with zero maintenance” because Meta and GitHub can change their APIs or policies. This setup avoids trials and subscriptions, refreshes the normal 60-day Instagram token every 35 days, and is designed to run continuously. A password change, removed app permission, disabled Meta app, or API change can still require reconnection.

## Part 1 — Prepare Instagram

1. Open Instagram on your phone.
2. Go to **Settings and activity → Account type and tools**.
3. Select **Switch to professional account → Business**.
4. Use a service category such as **Business Service** and keep the profile public.
5. Add a clear bio such as: `Private online form & document assistance in Delhi. Not a government authority. DM for help.`

## Part 2 — Create the free Meta connection

Meta changes Dashboard labels occasionally, but the required objects stay the same.

1. Open [Meta for Developers](https://developers.facebook.com/apps/), sign in and create a **Business** app.
2. Add the **Instagram** product and choose **API setup with Instagram Login**.
3. Add `@Virtual_cybercafe` as the Instagram account/tester when the setup asks for an account.
4. Grant `instagram_business_basic` and `instagram_business_content_publish`.
5. Generate a user access token for your own Professional Instagram account.
6. If Meta gives a short-lived token, exchange it for a long-lived token before continuing. Meta's Instagram access-token documentation is at `https://developers.facebook.com/docs/instagram-platform/reference/access_token`.
7. Get the numeric Instagram user ID shown in the API setup, or query:

   ```bash
   curl "https://graph.instagram.com/v26.0/me?fields=id,username&access_token=YOUR_TOKEN"
   ```

Do not send the token to anyone and never paste it into a public repository.

## Part 3 — Create the public GitHub repository

1. Create a new **public** GitHub repository, for example `virtual-cybercafe-instagram`.
2. Upload every project file while preserving folders such as `.github/workflows`, `src`, `config`, `scripts` and `state`.
3. On your computer, open the extracted project folder and run:

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   pip install -e .
   python tools/bootstrap_token.py
   ```

4. Paste the long-lived Instagram token only when the hidden prompt asks for it.
5. The script creates `state/instagram_token.enc` and prints one encryption key. The encrypted file may be committed; the printed key must remain secret.
6. Upload/commit `state/instagram_token.enc` and the updated `state/token_meta.json` to GitHub.

## Part 4 — Add GitHub secrets and variables

Open **Repository → Settings → Secrets and variables → Actions**.

Add these repository **Secrets**:

| Secret | Value |
|---|---|
| `IG_USER_ID` | Numeric Professional Instagram account ID |
| `TOKEN_ENCRYPTION_KEY` | Key printed by `bootstrap_token.py` |
| `GEMINI_API_KEY` | Optional; leave absent for the permanent template caption system |

Add these repository **Variables**:

| Variable | First value |
|---|---|
| `PUBLISH_MODE` | `dry-run` |
| `META_API_VERSION` | `v26.0` |
| `GEMINI_MODEL` | Optional: `gemini-2.5-flash-lite` |
| `PUBLISH_STATIC_POST` | `true` to publish the matching feed post; `false` for Reel only |

Then open **Settings → Actions → General → Workflow permissions**, choose **Read and write permissions**, and save. This is needed to update the encrypted token/state and the temporary media branch.

## Part 5 — Test before going live

1. Open **Actions → Daily Virtual Cyber Cafe Reel → Run workflow**.
2. Wait for the green check.
3. Download the one-day `instagram-dry-run-preview` artifact.
4. Review `reel.mp4`, `cover.jpg`, `static-post.jpg`, `caption.txt` and `static-caption.txt`.
5. If the preview is correct, change the repository variable `PUBLISH_MODE` from `dry-run` to `live`.
6. Run the workflow manually once more. It should publish the first Reel.

After that, GitHub schedules it daily at 14:00 UTC, which is 7:30 PM IST. Scheduled jobs can start a few minutes late when GitHub is busy; that does not create a duplicate.

## Content and timing controls

- Edit `config/services.yaml` to change topics, documents, titles or hashtags.
- Edit `config/brand.yaml` to change colours, CTA keyword, service area or disclaimer.
- To use your own licensed music, add it as `assets/custom_music.mp3`. Otherwise the original generated instrumental is used.
- Set `PUBLISH_STATIC_POST=false` if you want to generate the matching post but publish only the Reel.
- Edit `.github/workflows/daily-instagram.yml` to change the cron time.
- Edit `config/sources.yaml` to add an official notice page. Always add its exact official host to `allowed_hosts`.

Useful UTC → IST examples:

| India time | GitHub cron |
|---|---|
| 11:00 AM | `30 5 * * *` |
| 2:30 PM | `0 9 * * *` |
| 7:30 PM | `0 14 * * *` |
| 8:30 PM | `0 15 * * *` |

There is no universal “Instagram algorithm time.” Start at 7:30 PM for a Delhi consumer audience, then check Instagram Insights after 30 days and move the cron to the hour when your followers are most active.

## Live-form alert safety

The monitor reads titles and links only from the official domains in `config/sources.yaml`. It intentionally does not create deadlines, eligibility rules or vacancy numbers from guesses. Every live alert tells the viewer to verify the official notice. If a government site changes its HTML or blocks automated requests, that source is skipped and the scheduled evergreen service Reel is posted instead.

## Local preview command

With Python dependencies and FFmpeg installed:

```bash
python -m virtual_cybercafe.main prepare --skip-live
```

Output is written to `output/reel.mp4`, `output/cover.jpg`, `output/static-post.jpg`, `output/caption.txt` and `output/static-caption.txt`. This command does not publish anything.

## Troubleshooting

- **No Reel was posted:** confirm the account is Professional, `PUBLISH_MODE=live`, the two required permissions are present, and both required GitHub secrets are correct.
- **Media URL error:** confirm the repository is public and Actions has read/write permission.
- **Token error:** generate a new long-lived token, run `python tools/bootstrap_token.py` again, replace the encrypted token file and update the GitHub encryption-key secret.
- **Meta permission error:** reconnect the Professional account to the Meta app and grant the content-publishing permission.
- **Git push rejected:** remove branch protection from the generated `instagram-media` branch; do not remove protection from `main` unless it blocks the state commit.
- **Gemini quota error:** no action is required; the built-in caption fallback is automatic.

## Compliance

This project describes Virtual Cyber Cafe as a private assistance provider, not as a government authority. Do not request passwords, PINs or full payment-card details from customers. OTPs should be entered by the customer where possible. Confirm every live deadline and fee on the linked official portal before taking a customer's payment or submitting a form.
